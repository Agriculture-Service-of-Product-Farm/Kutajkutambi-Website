# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately**.

- Email: sbruicesingh@haclon.in
- Do **not** open a public GitHub issue or pull request for security reports.
- Include as much detail as possible (affected component, steps to reproduce, impact).

We will acknowledge receipt and work with you on a resolution timeline.

## Scope

This applies to the public information website and related research software under Agriculture Service of Product Farm (ASPF).

Detailed model internals, training data, and proprietary algorithms are confidential and not in scope for public disclosure.

## Supported Versions

Current public site and associated research releases.

## Disclosure Policy

Coordinated disclosure preferred. We aim to address confirmed issues promptly.
